Titanic Exploratory Data Analysis (EDA)

 Project Overview
This project performs an exploratory data analysis (EDA) on the Titanic dataset using Python. The objective is to clean the data, 
handle missing values, and visualize key survival factors such as passenger class, gender, and age distribution to draw meaningful academic insights.

Environment & Libraries
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
 Key Steps & Analysis
1. Data Loading & Inspection: Loaded the dataset, reviewed its structure, data types, and extracted summary statistics.
2. Data Cleaning: Identified missing values and successfully imputed missing entries in numerical columns (Age and Fare) using their respective medians.
3. Data Visualization & Insights:
   - Survival Rate by Passenger Class: Analyzed how ticket class affected survival probabilities, 
showing significantly higher survival rates for First Class passengers.
   - Survival Rate by Gender: Visualized the impact of gender on survival, reflecting historical priority policies where female survival rates were much higher.
   - Age Distribution: Examined the demographic structure of the passengers using a histogram and KDE plot.

Conclusion
The analysis successfully demonstrates the primary factors influencing passenger survival on the Titanic,
 highlighting the critical impact of passenger class and gender on survival rates
